# Project Overview
This project introduces essential networking concepts used in everyday systems administration. You will learn how hostname resolution works, how /etc/hosts influences DNS lookups, and how to inspect your machine’s active network interfaces. You will also practice modifying host resolution and using common network tools such as ifconfig, telnet, nc, and cut.

# Learning Objectives
By the end of this project, you should be able to explain, without external help:

General Networking Concepts
What localhost and 127.0.0.1 represent

What 0.0.0.0 means in networking

What the /etc/hosts file does

How to display your machine’s active network interfaces

How hostname resolution works before DNS

How tools like nc, telnet, and ping interact with network services
