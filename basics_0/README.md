# Overview
This project introduces fundamental networking concepts through practical Bash scripting and direct command‑line exploration. You will learn how devices communicate, how networks are structured, and how core protocols operate across the OSI model. By the end, you should be able to clearly explain essential networking principles without relying on external references.

# Learning Objectives
OSI Model
Understand what the OSI (Open Systems Interconnection) model is.

Identify its 7 layers and how they are organized from lowest (Layer 1) to highest (Layer 7).

Recognize the purpose of the Transport layer (TCP/UDP) and Network layer (IP/ICMP).

Network Types
Define a LAN (Local Area Network), its typical usage, and geographical size.

Define a WAN (Wide Area Network), its typical usage, and geographical size.

Understand what the Internet is as a global network of interconnected systems.

IP Addressing
Explain what an IP address is.

Distinguish between private and public IP addresses.

Understand IPv4 vs IPv6, and why IPv6 was created.

Define localhost and its purpose.

Understand what a subnet is and why subnetting is used.

Transport Protocols
Identify the two main transport protocols: TCP and UDP.

Explain the main differences between TCP and UDP.

Understand what a port is and memorize:

SSH → 22

HTTP → 80

HTTPS → 443

Network Tools & Diagnostics
Understand what ICMP is and how ping uses it to test connectivity.

Use basic networking commands:

ping

netstat

# Requirements
General
All Bash scripts must be written for Ubuntu 22.04.

Allowed editors: vi, vim, emacs.

Every file must end with a new line.

A README.md at the root of the project is mandatory.

All Bash scripts must be executable.

All scripts must pass shellcheck with no errors.

The first line of every Bash script must be:

Code
#!/usr/bin/env bash
The second line must be a comment describing the script’s purpose.

Answer Files
For multiple‑choice questions, include only the number of the correct answer.

Each answer must be on its own line.
